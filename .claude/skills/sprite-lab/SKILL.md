# Sprite Lab — стенд моделек

Инструмент визуальной полировки рисованных спрайтов. Страница `scripts/sprite-lab.html`
живьём рендерит всех врагов (со всеми состояниями: элита, ярость, телеграф залпа,
рывок, вспышка урона), сундуки и героя в разных костюмах, с анимацией (дыхание,
моргание, фитиль).

## Как пользоваться

1. Поднять dev-сервер, если не поднят: `preview_start` с конфигом `kok`
   (`python scripts/serve.py`, порт 8000). Стенд — статика, но модули грузятся
   только по http, не по file://.
2. Открыть в браузер-панели: `navigate` на
   `http://localhost:8000/scripts/sprite-lab.html`.
   **Важно:** после правки `dungeonSprites.js`/`character.js` всегда `navigate`
   заново — ES-модули кэшируются на время жизни страницы.
3. Смотреть глазами: `computer{action:"screenshot"}` для общего вида,
   `computer{action:"zoom", region:[...]}`/скейл-слайдер для деталей,
   `read_console_messages{onlyErrors:true}` — не упал ли рендер.
4. Править исходники → повторять с шага 2, пока не станет ровно.

## Что показывает

- Врагов: `chaser, shooter, tank, bomber, splitter, healer`, мини-босс, элита,
  боссов (`gunner`/`charger`) и их телеграфы, кадр получения урона.
- Сундуки в цветах предметов (М/Ф/лечение).
- Героя (`drawCharacter`) в образах: базовый, маг, рыцарь, принцесса — сверять
  костюмы гардероба.

Слайдер «масштаб» увеличивает без потери координатной сетки; чекбокс «сетка
пикселей» рисует шаг 8px — удобно для пиксельного стиля.

## Добавить новое

Новый вид врага/тайл — дописать ячейку в массивы `enemies`/`chests`/`heroes`
в `sprite-lab.html`. Ячейка: `{ label, draw(t, cx, cy) }`, где `t` — секунды
анимации, `cx,cy` — центр клетки.
