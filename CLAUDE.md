# CLAUDE.md

Правила работы в этом репозитории. Полное ТЗ — в `SPEC.md`, оно главнее этого файла.

## Проект

Образовательный 2D-платформер для детей 10–13 лет. Ванильный JavaScript, Canvas 2D,
без сборщика и без зависимостей. Открывается по ссылке как статика.

## Команды

```bash
python -m http.server 8000      # локальный запуск, открыть http://localhost:8000
node scripts/verify-tasks.mjs   # прогон всех генераторов задач по 100 раз
```

На Windows команда — `python`, а не `python3`: `python3` там обычно заглушка
Microsoft Store, которая откроет магазин вместо сервера. На macOS и Linux — `python3`.

Тестового фреймворка нет и не заводим. Проверка задач — самописный скрипт на голом Node.

## Жёсткие правила

- **Никаких зависимостей.** Нет `package.json`, нет `node_modules`, нет CDN-библиотек.
  Единственное внешнее — шрифты Google Fonts, всегда с системным фолбэком.
- **Никакого сборщика.** Только нативные ES-модули. В импортах пишем расширение:
  `import { player } from './game/player.js'`.
- **Только относительные пути.** Игра должна работать из подпапки на GitHub Pages.
- **Никакой сети во время игры.** Ни fetch к внешним API, ни аналитики, ни трекеров.
  Данные детей не собираются вообще.
- Файл `levels/*.json` правится руками — не генерируй уровни кодом на лету.

## Стиль кода

- ES2022, модули, `const` по умолчанию. Без TypeScript, без JSDoc-типизации всего подряд.
- Имена — по игровым понятиям: `chest`, `door`, `keyColor`, `coyoteTime`. Не `obj1`, не `manager2`.
- Один модуль — одна ответственность. Длиннее ~250 строк — дели.
- Числовые константы физики и геймплея — в одном месте (`src/engine/constants.js`),
  с комментарием, что значение подобрано на ощупь и его можно крутить.
- Комментарии объясняют «почему», а не «что». `// падаем быстрее, чем взлетаем — так
  прыжок читается отзывчивее` полезен; `// увеличиваем y` — нет.
- Без хардкода строк интерфейса в модулях — всё через `src/ui/i18n.js`.

## Как работаем

- Идём по этапам из раздела 11 `SPEC.md`. Каждый этап заканчивается **работающей сборкой**.
- Перед этапом — короткий план (файлы + подход). Перед большим рефакторингом — спроси.
- После этапа: запусти сервер, напиши, что именно проверить руками, и остановись.
  Не начинай следующий этап сам.
- Ошибка в консоли браузера = этап не сдан.
- Не переписывай уже принятые куски «заодно». Если видишь проблему в готовом коде —
  скажи о ней, не чини молча.

## Инварианты, которые нельзя ломать

- Игрок никогда не проваливается сквозь тайл, даже на максимальной скорости падения.
- Смерть от шипов/провала **не** отбирает уже полученные ключи и не сбрасывает решённые задачи.
- Задача никогда не блокирует прогресс навсегда: после трёх попыток показывается
  разбор и ключ выдаётся.
- `localStorage` всегда в `try/catch` — в приватном режиме игра работает без сохранения.
- Игра полностью проходима с клавиатуры, фокус всегда виден.
- `prefers-reduced-motion: reduce` отключает параллакс, тряску экрана и частицы.
