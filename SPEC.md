# ТЗ: «Ключи знаний» — образовательный 2D-платформер

Документ для Claude Code. Всё, что здесь написано — требования. Если требование
противоречит здравому смыслу или мешает игре быть играбельной — спроси, не додумывай.

---

## 1. Что делаем

Браузерный 2D-платформер в духе Mario для детей. Игрок бежит и прыгает по уровню,
собирает монеты, доходит до запертой двери. Дверь открывается ключом. Ключ лежит
в сундуке (или у NPC-стража) — при подходе открывается карточка с задачей по
**алгебре, геометрии или физике**. Решил → получил ключ → открыл дверь → следующий уровень.

Прогресс сохраняется: пройденные уровни, собранные монеты, статистика по задачам.

### Допущения (поменяй, если не так)

| Параметр | Принято | Где менять |
|---|---|---|
| Возраст игроков | 10–13 лет (5–7 класс) | сложность задач в `tasks/` |
| Язык интерфейса | русский | `src/i18n.js` (одна карта строк, готовим к en/tj) |
| Устройства | десктоп + мобильный браузер | обязательны экранные кнопки |
| Оффлайн | не требуется | — |

## 2. Ключевое требование: «запускается по ссылке»

Пробник должен открываться **по одной ссылке, без установки и без сборки**.

- Только статика: HTML + JS + CSS + JSON. Никакого бэкенда, никакой БД.
- **Без сборщика.** Нативные ES-модули (`<script type="module">`), импорты по
  относительным путям с расширением `.js`.
- **Без внешних библиотек.** Ни Phaser, ни React, ни npm-зависимостей. Canvas 2D API.
  Причина: нулевая настройка, мгновенная загрузка, всё читаемо и правится вручную.
- Шрифты — Google Fonts по CDN, с системным фолбэком, если CDN недоступен.
- Работает при открытии `index.html` через локальный сервер
  (`python3 -m http.server`) и после деплоя на GitHub Pages / Netlify как есть.
- Все пути — относительные (`./assets/...`), чтобы игра работала из подпапки
  вида `username.github.io/repo/`.

## 4. Игровая механика

### Движение
Платформер должен ощущаться отзывчиво. Это важнее «реалистичной» физики.

- Фиксированный шаг симуляции: 60 Гц (`dt = 1/60`), рендер — по `requestAnimationFrame`.
- Гравитация постоянная; падение быстрее подъёма (множитель ~1.6 к гравитации при `vy > 0`).
- **Variable jump height**: отпустил кнопку в подъёме → `vy *= 0.5`.
- **Coyote time**: 100 мс после схода с платформы прыжок ещё засчитывается.
- **Jump buffer**: нажатие за 120 мс до приземления срабатывает при касании земли.
- Горизонталь: ускорение + трение, не мгновенная скорость. В воздухе управление
  слабее наземного, но не отключается.
- Коллизии: AABB против тайловой сетки, раздельно по осям (сначала X, потом Y).
  Никаких проваливаний сквозь пол на высокой скорости — проверяй свип по вертикали.

### Управление

| Действие | Клавиатура | Мобильный |
|---|---|---|
| Влево / вправо | ←→ или A/D | экранные кнопки слева |
| Прыжок | Space / ↑ / W | круглая кнопка справа |
| Взаимодействие | E | та же кнопка при контакте с сундуком |
| Пауза | Esc | кнопка в углу HUD |

Мобильные кнопки — крупные (не меньше 64×64 CSS-px), полупрозрачные, появляются
только при наличии тач-события. Игра не должна скроллиться и зумиться пальцем.

### Объекты уровня

- **Монета** — очки, звук, +1 к счётчику. Чисто мотивация, на прогресс не влияет.
- **Сундук с задачей** — при взаимодействии ставит игру на паузу и открывает модалку.
  Решил → выдаёт ключ. Не решил → сундук остаётся, можно вернуться.
- **Ключ** — летит в HUD. Тип ключа (цвет) соответствует двери.
- **Дверь** — заперта, пока нет ключа нужного цвета. Открытая дверь = конец уровня.
- **Шип / провал** — respawn на последнем чекпоинте, минус жизнь. Жизней 3 на уровень,
  кончились — уровень с начала. **Задачи при этом не сбрасываются**: уже полученные
  ключи остаются. Наказывать за платформинг потерей учебного прогресса нельзя.
- **Чекпоинт** — флажок, сохраняет позицию респауна.
- **Движущаяся платформа** — по прямой между двумя точками, игрок едет вместе с ней.

Врагов в MVP нет. Сложность даёт геометрия уровня, а не бой.

## 5. Модуль задач — сердце проекта

### Формат задачи

Задачи — не статичные строки, а **генераторы с параметрами**, чтобы при повторном
прохождении числа менялись и нельзя было заучить ответ.

```js
// src/tasks/algebra.js
export const linearEquation = {
  id: 'algebra.linear.v1',
  subject: 'algebra',
  grade: [5, 6],
  difficulty: 1,
  generate(rng) {
    const a = rng.int(2, 9);
    const x = rng.int(1, 12);
    const b = rng.int(1, 20);
    return {
      prompt: `Реши уравнение: ${a}x + ${b} = ${a * x + b}`,
      answer: x,
      type: 'number',              // 'number' | 'choice' | 'input'
      unit: null,
      hint: 'Сначала перенеси свободное слагаемое в правую часть.',
      solution: `${a}x = ${a * x}; x = ${a * x} / ${a} = ${x}`
    };
  }
};
```

**Требования к движку задач:**

- Детерминированный `rng` с сидом, сид пишется в сохранение — при возврате на уровень
  задача та же, при новом прохождении — новая.
- Проверка числового ответа с допуском: `Math.abs(given - answer) <= (tolerance ?? 1e-6)`.
  Для физики с делением — `tolerance: 0.01` и явная единица измерения.
- Ответ принимается и с точкой, и с запятой (`3,5` === `3.5`).
- **Три попытки.** После первой неудачи — подсказка (`hint`). После третьей — показывается
  разбор (`solution`) и ключ **всё равно выдаётся**, но задача помечается как
  «решена с разбором» (в статистике другой цвет). Ребёнок не должен застревать в тупике.
- Задача выбирается по `subject`, `grade` и `difficulty`, заданным в JSON уровня.
- Каждая попытка логируется в сохранение: `{taskId, attempts, solvedAt, usedSolution}`.

### Стартовый банк (минимум 15 генераторов, по 5 на предмет)

**Алгебра:** линейное уравнение; нахождение неизвестного множителя; проценты от числа;
пропорция; упрощение выражения с приведением подобных.

**Геометрия:** периметр и площадь прямоугольника; площадь треугольника через основание
и высоту; сумма углов треугольника (найти третий); длина окружности; объём куба/параллелепипеда.

**Физика:** скорость через путь и время; плотность через массу и объём; путь при равномерном
движении; вес тела (`F = mg`, `g = 10 Н/кг`); работа (`A = F·s`).

Геометрические задачи **обязаны** иметь схематичный чертёж — рисуется прямо в модалке
через inline-SVG по параметрам задачи. Прямоугольник с подписанными сторонами читается
ребёнком в десять раз быстрее текста.

### Карточка задачи (UI)

- Затемняет игру, ставит на паузу, ловит фокус (focus trap), закрывается только
  решением или кнопкой «Вернуться» (тогда сундук остаётся закрытым).
- Крупный текст условия, чертёж/иллюстрация, поле ввода (`inputmode="decimal"`),
  кнопка «Проверить», счётчик попыток.
- Enter = «Проверить». Ошибка — короткая тряска поля и текст, что именно не так
  («число не подходит», а не «Ошибка!»). Правильно — анимация ключа, звук, автозакрытие через 1.2 с.
- Работает с клавиатуры целиком. Виден фокус.

## 6. Прогресс и сохранение

`localStorage`, один ключ `keysofknowledge.save.v1`, версионированная схема с миграцией.

```json
{
  "version": 1,
  "player": { "name": null, "coinsTotal": 42 },
  "levels": {
    "01": { "status": "completed", "coins": 12, "coinsMax": 15, "bestTimeMs": 84210, "stars": 2 },
    "02": { "status": "unlocked", "coins": 0, "stars": 0 },
    "03": { "status": "locked" }
  },
  "tasks": {
    "algebra.linear.v1": { "seen": 3, "solvedFirstTry": 2, "usedSolution": 1 }
  },
  "settings": { "sound": true, "music": true, "reducedMotion": false }
}
```

- Звёзды: 1 — уровень пройден, 2 — собрано ≥ 80% монет, 3 — все задачи решены без разбора.
- Экран выбора уровня показывает карту с замочками и звёздами.
- Кнопка «Сбросить прогресс» в настройках — с подтверждением.
- Обязательно `try/catch` вокруг `localStorage`: в приватном режиме он бросает исключение,
  игра при этом должна просто работать без сохранения, а не падать.

## 7. Уровни

Формат — JSON с тайловой сеткой. Размер тайла 32 px. Уровень описывается ASCII-картой:
читается человеком, правится в любом редакторе.

```json
{
  "id": "01",
  "title": "Первый ключ",
  "tileSize": 32,
  "spawn": [2, 10],
  "legend": {
    "#": "ground", "=": "platform", "^": "spike", "o": "coin",
    "C": "chest", "D": "door", "F": "checkpoint", ".": "empty"
  },
  "map": [
    "..........................",
    "........o.o.o.............",
    "......====================",
    "..@.......................",
    "###############^^#########"
  ],
  "chests": [
    { "at": [18, 3], "subject": "algebra", "grade": 5, "difficulty": 1, "keyColor": "amber" }
  ],
  "doors": [
    { "at": [24, 3], "keyColor": "amber" }
  ]
}
```

`levels/schema.md` описывает каждое поле — чтобы новый уровень добавлялся без чтения кода.

**Пять уровней MVP, с нарастанием:**

1. Плоская площадка, один сундук, одна дверь. Учим прыжок и взаимодействие. Задача уровня 1 — арифметическая.
2. Ямы и платформы. Два ключа разного цвета, две двери. Алгебра.
3. Движущиеся платформы, чекпоинт. Геометрия с чертежом.
4. Вертикальный подъём. Физика (скорость/время).
5. Всё вместе, три задачи разных предметов, финальная дверь.

Уровень проходится за 1.5–3 минуты. Ребёнок не должен уставать до задачи.

## 8. Визуал и звук

Направление — **ночная обсерватория**: тёмно-синее небо с созвездиями на фоне,
платформы как меловые линии на грифельной доске, ключи и монеты — тёплый янтарь.
Учебное и игровое живут в одном мире, а не воюют.

```css
--sky-deep:    #141B34;  /* фон */
--sky-mid:     #23305A;  /* дальний параллакс */
--chalk:       #E8ECF4;  /* платформы, контуры, текст */
--amber:       #F2A83B;  /* ключи, монеты, акцент */
--teal:        #3DBFA8;  /* верно, чекпоинты */
--coral:       #E5615F;  /* шипы, ошибка */
```

- Шрифты: **Rubik** 700–900 — заголовки и HUD; **Nunito** 400/600 — текст задач;
  **JetBrains Mono** — формулы и числа. Все три с кириллицей.
- Спрайты: если нет ассетов — рисуй фигурами Canvas (прямоугольники со скруглением,
  простые формы). Плейсхолдер-квадратики с текстом недопустимы даже в MVP.
- Параллакс фона в два слоя. При `prefers-reduced-motion: reduce` — статичный фон,
  без тряски экрана и без анимации частиц.
- Звук: прыжок, монета, ключ, верный ответ, ошибка, открытие двери. WebAudio,
  громкость по умолчанию 0.4, тумблеры в настройках. **Автовоспроизведение музыки запрещено** —
  только после первого клика игрока (иначе браузер заблокирует).
- Canvas масштабируется под окно с сохранением пропорций 16:9, `imageSmoothingEnabled = false`
  для чёткого пиксель-арта. Учитывай `devicePixelRatio`.

## 9. Чего НЕ делать

- Не подключать Phaser, React, Tailwind, Vite, бандлеры и npm-пакеты.
- Не делать бэкенд, аккаунты, рейтинги и любую отправку данных куда-либо.
  Дети играют — персональные данные не собираем вообще.
- Не ставить таймер на решение задачи. Спешка ломает обучение.
- Не показывать «Неверно!» с красным крестом на весь экран. Ошибка — часть процесса.
- Не блокировать прогресс на нерешённой задаче (см. правило трёх попыток).
- Никакой рекламы, внешних трекеров, аналитики.

## 10. Критерии приёмки

Игра готова, когда всё ниже верно:

- [ ] `index.html` открывается по ссылке и запускается без ошибок в консоли.
- [ ] Работает в Chrome, Safari, Firefox — десктоп и мобильный.
- [ ] Все 5 уровней проходятся от начала до конца.
- [ ] Персонаж не проваливается сквозь пол ни на какой скорости.
- [ ] 60 FPS на среднем ноутбуке; нет утечек — 10 минут игры без роста памяти.
- [ ] Прогресс переживает перезагрузку страницы; приватный режим не роняет игру.
- [ ] Не менее 15 генераторов задач, все дают корректный ответ на 100 прогонах
      (есть скрипт-проверка `npm`-free: `node scripts/verify-tasks.mjs`).
- [ ] Геометрические задачи показывают чертёж.
- [ ] Вся игра проходима с клавиатуры; фокус виден; модалка ловит фокус.
- [ ] `prefers-reduced-motion` уважается.
- [ ] README объясняет, как добавить уровень и задачу, за 5 минут.

## 11. План работ (по этапам, каждый — рабочая сборка)

Не берись за следующий этап, пока предыдущий не запускается и не проверен вручную.

1. **Каркас.** `index.html`, canvas, игровой цикл, ввод, рендер тайлмапа из хардкод-массива.
   Результат: белый квадрат ездит по платформам.
2. **Физика и ощущение.** Гравитация, коллизии, coyote time, jump buffer, камера, чекпоинты.
   Результат: прыгать приятно. Здесь остановись и попроси проверить, прежде чем идти дальше.
3. **Сущности.** Монеты, сундук, ключ, дверь, шипы, движущиеся платформы. Загрузка уровня из JSON.
4. **Задачи.** Движок задач, `rng` с сидом, 15 генераторов, модалка, чертежи на SVG.
5. **Прогресс.** Сохранение, меню, экран выбора уровня, звёзды, настройки.
6. **Уровни.** Пять уровней с нарастанием сложности.
7. **Полировка.** Визуал, звук, мобильные кнопки, доступность, README, деплой.
