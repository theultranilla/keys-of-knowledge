# Ключи знаний

Образовательный 2D-платформер для детей 10–13 лет. Бежишь, прыгаешь, находишь сундук,
решаешь задачу по математике / физике, получаешь ключ, открываешь дверь.

Ванильный JavaScript, Canvas 2D, нативные ES-модули. Без зависимостей, без сборщика,
без бэкенда — открывается как статика по одной ссылке.

## Запуск

Просто дважды кликнуть по `index.html` **нельзя**: браузер запрещает ES-модули с
`file://`. Нужен локальный сервер.

```bash
python scripts/serve.py
```

На macOS и Linux — `python3 scripts/serve.py`. Дальше открыть <http://localhost:8000>.

Это обычный `http.server` из стандартной библиотеки плюс заголовок, запрещающий
кэш: правки в уровнях и коде видны сразу после перезагрузки, без Ctrl+F5.
Зависимостей по-прежнему ноль.

## Управление

| Действие | Клавиши | На телефоне |
|---|---|---|
| Бежать | `←` `→` или `A` `D` | кнопки слева внизу |
| Прыжок | `Space`, `↑` или `W` | круглая кнопка справа |
| Открыть сундук | `E` вплотную к сундуку | кнопка `E` справа |
| Пауза | `Esc` | кнопка в правом верхнем углу |
| Застрял — вернуться на флажок | `R` | кнопка `⟲` в левом верхнем углу |

Экранные кнопки появляются только после первого касания экрана: на десктопе они
не нужны и не мешают.

`R` лопает игрока и возвращает на последний чекпоинт. Это не украшение, а
страховка: если геометрия уровня загнала в угол, откуда не выпрыгнуть, без такой
кнопки единственный выход — перезагрузка страницы. При `prefers-reduced-motion`
осколков нет, возврат мгновенный.

WASD работает и на русской раскладке: ввод читает физический код клавиши, а не букву.

## Что сделано (все 7 этапов)

Игра готова: пять уровней, задачи в сундуках, прогресс со звёздами, звук,
экранное управление для телефона.

| Уровень | Что нового | Предмет |
|---|---|---|
| 01 «Первый ключ» | ровная площадка, учим прыжок и `E` | математика |
| 02 «Два ключа» | ямы, два ключа, ворота посреди пути | математика |
| 03 «На весу» | движущиеся платформы, чекпоинт | математика |
| 04 «Наверх» | вертикальный подъём зигзагом | физика |
| 05 «Обсерватория» | всё вместе, три ключа, шипы | математика + физика |

Запертая дверь твёрдая: ворота посреди уровня не пускают дальше без ключа.
Уровень заканчивает та дверь, что помечена в JSON как `"exit": true`.

Звёзды складываются: одна за прохождение, вторая за 80% монет, третья — если все
задачи уровня решены без разбора.

## Как добавить задачу

Открой файл нужного предмета в `src/tasks/`, допиши генератор и внеси его в
массив в конце файла:

```js
export const myTask = {
  id: 'math.mytask.v1',
  subject: 'math',           // math | physics
  grade: [2, 3],             // на какие классы рассчитана (1–5)
  difficulty: 1,             // 1-3
  generate(rng) {
    const a = rng.int(2, 9); // rng сидирован: те же числа при возврате к сундуку
    return {
      prompt: `Сколько будет ${a} + ${a}?`,
      answer: a + a,
      type: 'number',
      unit: null,            // 'см', 'м/с' — покажется рядом с полем ввода
      hint: 'Появится после первой ошибки.',
      solution: 'Появится после третьей.'
    };
  }
};
```

Числа подбирай так, чтобы ответ был целым. Если целым он быть не может, задай
`tolerance` — иначе ребёнок напишет округлённое число и получит «не подходит».
Геометрическая задача возвращает `figure` — см. виды чертежей в `src/ui/figures.js`.

Проверить: `http://localhost:8000/scripts/verify-tasks.html`. Скрипт прогоняет
каждый генератор по 100 раз и ловит пустые условия, нецелые ответы без допуска,
отсутствие чертежа у геометрических задач и несовпадение задачи при одном и том же сиде.

## Как добавить уровень

**Проще всего — редактор.** Открой `http://localhost:8000/scripts/level-editor.html`:
рисуешь тайлы мышью, ставишь сундуки/двери/пружины/кометы, жмёшь «Проверить»
(тот же аудит, что и в игре) и выгружаешь готовый JSON. Его остаётся положить в
`levels/` и вписать `id` в `order` (см. ниже). Редактор умеет и импорт — вставь в
поле готовый уровень, чтобы его поправить.

Руками: скопируй `levels/01.json`, поменяй `id`, `title` и карту — все поля
описаны в [levels/schema.md](levels/schema.md). Затем впиши новый `id` в `order`
в [levels/index.json](levels/index.json): список файлов в папке из браузера не
виден, а меню должно знать, какие уровни есть и в каком они порядке.

Проверить: открой `http://localhost:8000/scripts/audit-levels.html` — аудит
пройдёт уровень честной симуляцией и скажет, добираешься ли ты до каждого
сундука и до выхода и нет ли места, откуда не выбраться. Отдельный уровень
открывается по ссылке `?level=02`.

Разбор уровня придирчивый нарочно. Съехала дверь на колонку в сторону — игра не
запустится и скажет ровно это, вместо того чтобы молча положить дверь в стену.

Почему прыжок ощущается именно так:

- **Coyote time, 100 мс.** Сошёл с края — прыжок ещё засчитывается. Игрок почти
  всегда жмёт кнопку на кадр позже, чем думает.
- **Jump buffer, 120 мс.** Нажал перед самым приземлением — прыгнешь сразу, как
  коснёшься земли.
- **Variable jump.** Держишь кнопку — 79 px подъёма, коротко нажал — 25 px.
- **Падение быстрее подъёма** (×1.6 к гравитации): зависание в верхней точке
  читается как ватность.

## Выложить в интернет

Игра — чистая статика без сборки, поэтому выкладывается как есть.

**GitHub Pages.** Залей репозиторий на GitHub, открой Settings → Pages, в разделе
Build and deployment выбери Deploy from a branch, ветку `main` и папку `/ (root)`.
Через минуту игра будет по адресу `https://<логин>.github.io/<репозиторий>/`.

Все пути в коде относительные, а уровни грузятся относительно своего модуля
через `import.meta.url` — из подпапки всё работает без правок.

**Netlify.** Перетащи папку проекта в окно netlify.com/drop. Ни команды сборки,
ни каталога публикации указывать не нужно.

Что проверить после выкладки: открылось меню, уровень запустился, в консоли
пусто. Если пусто не в консоли, а на экране — почти наверняка не подхватились
`levels/*.json`: проверь, что папка `levels` попала в репозиторий.

## Что проверяется автоматически

| Страница | Что проверяет |
|---|---|
| `scripts/verify-tasks.html` | 15 генераторов задач по 100 прогонов |
| `scripts/audit-levels.html` | проходимость всех уровней и капканы |

Обе открываются на локальном сервере и не требуют ничего, кроме браузера.

Полное ТЗ — в [SPEC.md](SPEC.md), правила работы над кодом — в [CLAUDE.md](CLAUDE.md).

## Как поправить ощущение от прыжка

Все числа лежат в [src/engine/constants.js](src/engine/constants.js) с комментариями.
Прыжок выше — увеличить `JUMP_SPEED`. Персонаж тяжелее — увеличить `GRAVITY`.
Разгон резче — увеличить `RUN_ACCELERATION`. Значения подобраны на ощупь, их можно крутить.
