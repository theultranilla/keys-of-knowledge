# Ключи знаний

Образовательный 2D-платформер для детей 10–13 лет. Бежишь, прыгаешь, находишь сундук,
решаешь задачу по алгебре / геометрии / физике, получаешь ключ, открываешь дверь.

Ванильный JavaScript, Canvas 2D, нативные ES-модули. Без зависимостей, без сборщика,
без бэкенда — открывается как статика по одной ссылке.

## Запуск

Просто дважды кликнуть по `index.html` **нельзя**: браузер запрещает ES-модули с
`file://`. Нужен любой локальный сервер.

```bash
python -m http.server 8000
```

На macOS и Linux — `python3 -m http.server 8000`.

Дальше открыть <http://localhost:8000>.

## Управление

| Действие | Клавиши |
|---|---|
| Бежать | `←` `→` или `A` `D` |
| Прыжок | `Space`, `↑` или `W` |
| Открыть сундук | `E` вплотную к сундуку |
| Застрял — вернуться на флажок | `R` |

`R` лопает игрока и возвращает на последний чекпоинт. Это не украшение, а
страховка: если геометрия уровня загнала в угол, откуда не выпрыгнуть, без такой
кнопки единственный выход — перезагрузка страницы. При `prefers-reduced-motion`
осколков нет, возврат мгновенный.

WASD работает и на русской раскладке: ввод читает физический код клавиши, а не букву.

Экранные кнопки для телефона появятся на Этапе 7.

## Как добавить задачу

Открой файл нужного предмета в `src/tasks/`, допиши генератор и внеси его в
массив в конце файла:

```js
export const myTask = {
  id: 'algebra.mytask.v1',
  subject: 'algebra',        // algebra | geometry | physics
  grade: [5, 6],             // на какие классы рассчитана
  difficulty: 1,             // 1-3
  generate(rng) {
    const a = rng.int(2, 9); // rng сидирован: те же числа при возврате к сундуку
    return {
      prompt: `Сколько будет ${a} + ${a}?`,
      answer: a + a,
      type: 'number',
      unit: null,            // 'см', 'м/с' — покажется рядом с полем ввода
      hint: 'Появится после первой ошибки.',
      solution: 'Появится после третьей.'
    };
  }
};
```

Числа подбирай так, чтобы ответ был целым. Если целым он быть не может, задай
`tolerance` — иначе ребёнок напишет округлённое число и получит «не подходит».
Геометрия обязана вернуть `figure` — см. виды чертежей в `src/ui/figures.js`.

Проверить: `http://localhost:8000/scripts/verify-tasks.html`. Скрипт прогоняет
каждый генератор по 100 раз и ловит пустые условия, нецелые ответы без допуска,
отсутствие чертежа у геометрии и несовпадение задачи при одном и том же сиде.

## Как добавить уровень

Скопируй `levels/01.json`, поменяй `id`, `title` и карту — всё поле описано в
[levels/schema.md](levels/schema.md). Регистрировать уровень нигде не нужно.
Проверить: открыть `http://localhost:8000/?level=02`.

Разбор уровня придирчивый нарочно. Съехала дверь на колонку в сторону — игра не
запустится и скажет ровно это, вместо того чтобы молча положить дверь в стену.

Почему прыжок ощущается именно так:

- **Coyote time, 100 мс.** Сошёл с края — прыжок ещё засчитывается. Игрок почти
  всегда жмёт кнопку на кадр позже, чем думает.
- **Jump buffer, 120 мс.** Нажал перед самым приземлением — прыгнешь сразу, как
  коснёшься земли.
- **Variable jump.** Держишь кнопку — 79 px подъёма, коротко нажал — 25 px.
- **Падение быстрее подъёма** (×1.6 к гравитации): зависание в верхней точке
  читается как ватность.

## Как поправить ощущение от прыжка

Все числа лежат в [src/engine/constants.js](src/engine/constants.js) с комментариями.
Прыжок выше — увеличить `JUMP_SPEED`. Персонаж тяжелее — увеличить `GRAVITY`.
Разгон резче — увеличить `RUN_ACCELERATION`. Значения подобраны на ощупь, их можно крутить.
